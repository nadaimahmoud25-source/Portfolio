# Nada Ibrahim — Product Design Portfolio

Live site: https://nadaimahmoud25-source.github.io/Portfolio/

- `index.html` — landing page
- `awaed-web-trader.html`, `options-trading.html` — case studies
- `assets/` — screenshots
- `js/` — small runtime (Preact + `dc.js`) that powers the interactive bits

The pages are exported from the Claude Design artifact "Nada Ibrahim Portfolio".
`design-source/` keeps the original `.dc.html` files; `tools/build.js` turns them into the pages:

```
node tools/build.js design-source .
```
